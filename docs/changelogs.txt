## Version 1.7 | Latest Release | September 7, 2026
- Qualcomm Snapdragon SoC Temp Fix: Corrected silicon temperature reading on Qualcomm platforms by reading raw cpu-*-usr and gpuss-*-usr thermal zones rather than PMIC battery percentage.
- Dedicated CPU & GPU Temp Toggles: Added separate switches in Display Settings to monitor live CPU and GPU temperatures independently on the overlay.
- Adaptive Multi-Line Layout: Sleek single-line pill for 1 to 3 active overlays, automatically organizing into 2 balanced lines (Performance metrics and Thermals) when 4 or more are active.
- Cross-Platform Hardware Verification: Fully verified across both Qualcomm Snapdragon and MediaTek Dimensity devices.

## Version 1.6 | v1.6 | September 6, 2026
- Real-Time SoC Temperature Monitoring: Query Android Thermal HAL (dumpsys thermalservice) via Shizuku privileged shell access to display live CPU/GPU processor hotspot thermals alongside battery temperature.
- Independent Temperature Toggles: Choose between Battery Temp, SoC Temp, or dual monitoring with compact BATT and SOC overlay tags.
- Built-in Crash Reporter: Process-isolated error activity (:crash) with instant clipboard copying, share sheet integration, and direct GitHub issue filing with pre-filled Markdown reports.
- Landscape Layout Guard: Strict single-line enforcement on the pill overlay prevents wrapping or clipping in wide aspect ratios.
- Stability & Upgrade Protection: Resolved UninitializedPropertyAccessException in FpsOverlayService during app upgrades and cold starts.

## Version 1.4 | v1.4 | September 2, 2026
- SurfaceFlinger Game FPS Provider: Privileged frame monitoring using Shizuku to inspect compositor layers and sample real frame presentation buffers directly from active game SurfaceView buffer queues.
- Automatic Graphics API Detection: Dynamically inspects foreground game rendering pipelines via system GPU telemetry to detect Vulkan or OpenGL ES.
- Graphics API Overlay Badge: Optional on-screen [VK] or [GL] badge displayed on the overlay pill next to the FPS value.
- Self-Healing Layer Recovery: Automated active layer invalidation and presentation timestamp resynchronization to prevent 0 FPS stalls during game switches and splash screens.
- Graceful Fallback Mechanism: Automatically falls back to Choreographer display vsync measurement if Shizuku is stopped or permissions are revoked.

## Version 1.0 | v1.0 | April 18, 2026
- Initial Release: Lightweight, high-performance real-time FPS monitoring overlay for Android inspired by Samsung Perf Z.
- Choreographer FPS Engine: Display vsync frame timing measurement with low CPU and battery overhead.
- Real-Time Telemetry: Live FPS counter, frame time in milliseconds (MS), and battery temperature in Celsius (TEMP).
- Dynamic Color Thresholds: Real-time color-coded FPS display based on performance drops (green, yellow, orange, red).
- Custom Positioning: Six preset screen positions (top/bottom left/center/right) with freehand drag-and-drop repositioning.

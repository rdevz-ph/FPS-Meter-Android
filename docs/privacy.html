shield Overview

FPS Meter Android is an open-source performance and telemetry monitoring utility for Android devices. This privacy policy explains how the application treats your data.

The application is built with a strict privacy-first principle: it operates entirely offline on your device. The app does not collect, record, track, transmit, or sell any personal information.

visibility_off Information We Do Not Collect

FPS Meter Android does not gather any information about you or your device. Specifically:

  • No Personal Identifiers: We do not collect names, email addresses, phone numbers, contacts, or account credentials. There is no account registration or login required.
  • No Device Identifiers: We do not collect advertising IDs, IMEI numbers, MAC addresses, or Android hardware IDs.
  • No Analytics or Tracking: The app contains no third-party analytics SDKs, trackers, or telemetry endpoints.
  • No Crash Reporting Services: No automatic crash dumps or device logs are sent to external servers.
  • No Internet Communication: The app does not transmit any performance metrics or usage patterns over the internet.

speed How Performance Data Is Handled

All metrics calculated by FPS Meter Android are generated locally in real time:

  • Frames Per Second (FPS) and Frame Times: Measured using local frame callbacks (Android Choreographer API) or compositor buffer queries (SurfaceFlinger via Shizuku).
  • Battery Information: Read directly from Android's standard local battery change broadcasts to show current battery temperature and battery level.
  • Hardware Temperatures: Read locally from device thermal sensors and Linux thermal zones via Shizuku shell commands.

These readings exist only in active device memory to render the on-screen overlay and are never transmitted outside your device.

lock_open Device Permissions and Their Purposes

The application requests specific Android permissions strictly to deliver its core monitoring features:

  • Display Over Other Apps (SYSTEM_ALERT_WINDOW): Required to draw the floating FPS monitor overlay and the assistive floating bubble on top of active games and apps.
  • Foreground Service (FOREGROUND_SERVICE_SPECIAL_USE): Allows the overlay service to run in the background while you play games, showing a persistent system notification so you are always aware the monitor is running.
  • Accessibility Service (FpsAccessibilityService): This is an optional feature. When enabled by the user, it detects when user-selected games launch or close, allowing the overlay to start and stop automatically. The service does not read, inspect, log, or record screen text, personal messages, keystrokes, or user input. Screen content retrieval is explicitly disabled in the service configuration (canRetrieveWindowContent="false").
  • Shizuku Privileged Shell (Optional): When granted by the user, Shizuku allows the app to query SurfaceFlinger for actual game frame presentation timestamps and read system thermal sensors. All shell commands are executed locally on the device; no shell outputs leave your phone.

save Local Storage and User Control

Any data created while using FPS Meter Android is stored locally in the application's private storage directory on your device:

  • Benchmark History: If you use the session recording feature, summary statistics (average FPS, peak FPS, minimum FPS, duration, and timestamp) are stored in the local SQLite database.
  • App Preferences: Your overlay settings, active metrics, layout positions, and target games list are stored locally using Android SharedPreferences.

You have full control over this data. You can delete individual session records or wipe all history from within the History screen at any time. Clearing the app's storage or uninstalling the app permanently removes all local data.

share Scorecard Sharing

When you choose to share a benchmark scorecard, the app generates an image file in the local cache directory of the app.

The generated scorecard is passed directly to Android's native system share sheet. The app never uploads the image to any remote server. The file is sent only to the destination app you choose (such as a messaging app or email client).

extension_off Third-Party Services

FPS Meter Android does not use third-party software development kits (SDKs) for advertising, behavior tracking, user profiling, or remote telemetry.

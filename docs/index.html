Core Capabilities

Designed for Competitive Mobile Gamers

True SurfaceFlinger FPS

Unlike standard apps that only measure UI vsync timing, SurfaceFlinger mode hooks into compositor presentation buffers to measure true gameplay frame rates.

Graphics API Detection

Automatically identifies whether your active game is running on Vulkan or OpenGL ES, displaying a crisp [VK] or [GL] badge on the overlay.

Dual Thermal Telemetry

Monitor your device’s battery temperature and the processor SoC hotspot in real time to prevent thermal throttling before it causes stutters.

Samsung Perf Z Pill Styling

Clean semi-transparent dark pill with cyan telemetry labels, white digits, and dynamic green-yellow-orange-red color thresholds based on framerate drops.

Quick Settings & Floating Bubble

Toggle the overlay on or off without leaving your game via an Android Quick Settings status bar tile or an edge-snapping floating assistive button.

Auto Game Detection

Configurable Accessibility Service automatically starts monitoring the moment your selected games launch and turns off immediately when you exit.

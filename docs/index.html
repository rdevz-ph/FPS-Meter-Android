Changelog & Updates

Release History

Core Capabilities

Designed for Competitive Mobile Gamers

speed

True SurfaceFlinger FPS

Unlike standard apps that only measure UI vsync timing, SurfaceFlinger mode hooks into compositor presentation buffers to measure true gameplay frame rates.

memory

Graphics API Detection

Automatically identifies whether your active game is running on Vulkan or OpenGL ES, displaying a crisp [VK] or [GL] badge on the overlay.

battery_charging_full

Battery & Thermal Telemetry

Monitor real-time thermals across CPU, GPU, SoC, and Battery, plus live battery percentage. Merges into a compact unified readout (BAT 38°C (85%)) when both are active.

fiber_manual_record

In-Memory FPS Recording

Lightweight per-game session recording aggregates average FPS, peak FPS, min FPS, and session duration in memory without disk I/O lag or battery drain.

history

Session Performance History

Dedicated History tab stores benchmark runs for each game with average FPS badges, duration tags, timestamps, and full session log management.

sports_esports

Direct Game Launcher

Built-in Games screen allows launching your installed games directly with 1 tap, alongside quick search filtering and per-game recording toggles.

bubble_chart

Assistive Menu & Quick Settings

Expandable floating bubble provides an in-game HUD menu to start/stop game FPS recording and toggle overlay visibility without leaving the game.

tune

Samsung Perf Z Pill Styling

Clean semi-transparent dark pill with cyan telemetry labels, white digits, and dynamic green-yellow-orange-red color thresholds based on framerate drops.

smart_toy

Auto Game Detection

Configurable Accessibility Service automatically starts monitoring the moment your selected games launch and turns off immediately when you exit.
